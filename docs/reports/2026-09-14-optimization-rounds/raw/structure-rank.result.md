# Structure rank-map prototype

Variant: `structure-rank`, based on detached `4de75d4` with the clamped sparse table-cell map applied first.

## Change

Replaced the per-removal binary-search table-cell source map with a compact rank index. Removed bytes are represented by one bit per generated byte in 64-byte blocks, with a `u32` prefix count per block. Boundary remapping clamps to the generated content length, then computes `bounded + prefix + popcount(bits before boundary)` in constant time. The map is built while unescaping escaped table pipes, so it does not perform a second source scan or quadratic map construction.

## Result

The candidate remains semantically correct under focused parser and table span checks. It is archived for parent-controlled performance measurement; no timing was performed in this worktree.
