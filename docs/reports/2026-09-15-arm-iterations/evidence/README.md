# Original session evidence

This directory preserves the original Apple Silicon iteration session that
produced the report one level up. The complete payload is in
[`original-session.tar.gz`](original-session.tar.gz). `attempts.tsv` inside the
archive maps each build directory to its recorded baseline and candidate
revision, associated result directories, and reconstructed source patch.
The archive's `MANIFEST.sha256` checks every extracted file, and the adjacent
`.sha256` sidecar checks the compressed payload itself.

The deterministic gzip archive uses tar hardlinks for byte-identical files and
omits macOS metadata. Its 59,567,316 bytes restore 710 files, including the
manifest: 42 result sets and 30 build records with reconstructed patches. The
[independent audit](artifact-audit.json) verifies all 709 manifest entries,
673 copies against their original session files, and all 30 patches by applying
them to their frozen baseline trees and checking the resulting candidate tree
hashes. One mixed CPU-control build resolves its unnamed candidate snapshot
through an identical retained source-tree hash, as recorded in the audit.

Verify the sidecar from this directory, then extract into an empty directory:

```sh
shasum -a 256 -c original-session.tar.gz.sha256
mkdir /private/tmp/arm-evidence-replay
tar -xzf original-session.tar.gz -C /private/tmp/arm-evidence-replay
cd /private/tmp/arm-evidence-replay
shasum -a 256 -c MANIFEST.sha256
```

The archive contains:

- every recorded `samples.json`, `verification.json`, summary, run, arena, and
  grouped result file from `/private/tmp/fmv2-arm/res-*`;
- the shared corpus and all generated Markdown inputs;
- each build's `build.json`, frozen `worker.rs`, Cargo manifests and locks, and
  build log, without compiled outputs;
- `patches/build-*.patch`, generated by comparing each candidate source tree
  with the baseline tree identified by its `source_tree_sha256` (a baseline
  snapshot reused by another build is named in `source-hashes.tsv`);
- the source-tree and source-manifest hashes recorded by the harness, so the
  unmodified baselines remain identifiable without copying every source
  snapshot;
- compact `p3-*.xml` and sampled JSON profiler exports; these preserve the
  exported profile data used for the report but are not a complete profiler
  session replay.

Build and result paths in the original temporary directory were session-local.
The archive keeps the recorded revisions, source hashes, worker hashes, build
flags, and result names; it does not infer a commit for a dirty candidate.
The `build-01` through `build-16b` names therefore remain the primary attempt
identifiers. The `res-bisect-*` directories are retained as separate replay
results and are mapped in `attempts.tsv`.

Compiled binaries, Cargo `target` directories, complete source snapshots, and
the large xctrace trace stores are intentionally excluded. The archive records
the compact exports and build/source hashes, but it does not claim to provide a
full profiler replay or preserve every trace-store detail. The session used a
local replacement for the harness prepare step, and that session-local script
was not present in the repository, so the archive records the resulting
manifests and hashes rather than claiming the missing script is reproducible.

The archive is evidence only. It does not alter the historical measurements in
the report and no builds, tests, or benchmark runs are part of its creation.
