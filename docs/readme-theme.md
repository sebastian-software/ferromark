# README themes

Edit `README.md.src`, then run `mise run readme:write` and `mise run readme:check`.
Install the pinned generator with `mise trust` and `mise install --locked`.
`README.md` is generated by mdtheme using the Sebastian Software and Ferramenta
frames pinned in `mdtheme.yaml`. Never edit generated branding by hand.

Keep source and output together. Run `python3 scripts/publish-native-readme.py`
to regenerate the current benchmark section, then run mdtheme. `--check` verifies
the section against its archived measurements. The wrapper runs the frozen
publisher in a temporary copy, preserving archived report checksums. The npm README retains its separate compact family generator:
`node scripts/check-readme-family.mjs --write`.
