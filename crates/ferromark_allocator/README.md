# ferromark_allocator

Arena allocation shared by the Ferromark parser, syntax tree, and renderer.

This package is part of [Ferromark](https://github.com/sebastian-software/ferromark).
See the [API documentation](https://docs.rs/ferromark_allocator) and
[v2 migration guide](https://github.com/sebastian-software/ferromark/blob/main/docs/migration-v2.md).

Most applications should depend on the [ferromark facade](https://crates.io/crates/ferromark).
