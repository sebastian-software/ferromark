# Start with Node.js

Render Markdown in a Node.js application with a synchronous, native API.
Use **Node.js 22.12 or newer**. TypeScript declarations are included.

## Install

```sh
npm install ferromark
```

npm's `latest` channel carries {version}. V2 is a breaking change from v1.
Read the [migration guide](https://github.com/sebastian-software/ferromark/blob/main/docs/migration-v2.md) before upgrading.

Save this as `example.mjs` and run `node example.mjs`:

```js
import { toHtml } from "ferromark";

const html = toHtml("# Hello\n\n**World**");
console.log(html);
```

The result is:

```html
<h1 id="hello">Hello</h1>
<p><strong>World</strong></p>
```

For CommonJS, use `const { toHtml } = require('ferromark')` on a supported Node.js
version. You do not need to install a compiler: npm selects a prebuilt native
package for your platform.

## Choose your API

| Your task                      | API                                | Result                                |
| ------------------------------ | ---------------------------------- | ------------------------------------- |
| Render one document            | `toHtml(markdown, options?)`       | HTML string                           |
| Send HTML as bytes             | `toHtmlBuffer(markdown, options?)` | UTF-8 `Buffer`                        |
| Get HTML and metadata          | `transform(markdown, options?)`    | HTML, headings, optional front matter |
| Render many documents          | `new Renderer(options?)`           | Reuses native parser scratch          |
| Highlight code                 | `toHtmlWithHighlighter()`          | HTML with custom code-block output    |
| Highlight and collect metadata | `transformWithHighlighter()`       | HTML, headings, optional front matter |

Every call that takes Markdown accepts `markdown: string | Uint8Array`: a string,
or its UTF-8 bytes in a `Uint8Array` such as a `Buffer` from `fs.readFile(path)`.
[Render a file from bytes](/node/pipelines) shows the example.

These calls are synchronous. For sustained CPU work in a server, use a worker
thread so rendering does not occupy the request-handling event loop.

## Compile JSX for a build pipeline

For trusted authored content, `compileJsx` produces a JSX body or a complete MDX
module. `JsxCompiler` adds native highlighting, prepared documents for metadata
and repeated rendering, and standalone code-block rendering. Your application's
JSX transform compiles the output. See the
[Node JSX guide](https://github.com/sebastian-software/ferromark/blob/main/docs/jsx-node.md)
for API selection and complete examples, including how to try additions on
`main` before their release. [MDX boundaries](/guide/mdx) explains the difference
between HTML syntax capture and JSX compilation.
