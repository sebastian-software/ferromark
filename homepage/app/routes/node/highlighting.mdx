# Highlight Code and Render Diagrams in Node.js

import { RuntimeSwitch } from "../../components/runtime-switch";

<RuntimeSwitch topic="highlighting" />

Connect an initialized Ferriki highlighter and, optionally, a Ferrigura diagram
renderer. Ferromark keeps its own code block markup, so line numbers, highlighted
lines, titles, and your JSX code block component keep working.

## Install and initialize

```sh
npm install ferromark @ferriki/core
```

Create the highlighter once and reuse it. Load the themes and languages your
content needs:

```js
import { createHighlighter } from "@ferriki/core";
import { createLineHighlighter } from "ferromark";

const themes = {
  light: "github-light-default",
  dark: "github-dark-default",
};
const highlighter = await createHighlighter({
  themes: Object.values(themes),
  langs: ["javascript", "rust"],
});

const highlightCodeBlock = createLineHighlighter(highlighter, {
  themes,
  onHighlightError(error, { lang }) {
    console.warn(`Could not highlight ${lang}`, error);
  },
});
```

Pass `theme: "github-dark"` instead of `themes` for a single theme.
Initialization is asynchronous; rendering is synchronous.

## Render HTML

```js
import { toHtmlWithCodeRenderer, transformWithCodeRenderer } from "ferromark";
import { readFile } from "node:fs/promises";

const source = await readFile("guide.md", "utf8");
const hooks = { highlightCodeBlock };
const html = toHtmlWithCodeRenderer(source, hooks, { headingIds: true });

// The same hooks, with headings and front matter.
const page = transformWithCodeRenderer(source, hooks, { frontMatter: true });
console.log(page.headings, page.frontMatter);
```

Ferromark writes the `<pre><code>` wrapper and the language class around the
highlighted lines. The highlighter only colors tokens.

## Compile JSX

```js
import { compileJsx } from "ferromark";

const options = { codeBlockComponent: "CodeBlock" };
const { body } = compileJsx(source, options, hooks);
```

JSX output also applies fence metadata: `{1}` marks highlighted lines and
`title="…"` becomes a title. `CodeBlock` receives the original code, language,
and title as props and the highlighted `<pre>` as children. With a theme pair,
the colors arrive as `--shiki-light` and `--shiki-dark` CSS variables.

## Add Mermaid diagrams

```sh
npm install @ferrigura/core
```

```js
import { Renderer } from "@ferrigura/core";
import { composeCodeHooks, createDiagramCodeRenderer } from "ferromark";

const diagrams = createDiagramCodeRenderer(new Renderer(), {
  colorScheme: "auto",
});
const withDiagrams = composeCodeHooks(diagrams, { highlightCodeBlock });
const html = toHtmlWithCodeRenderer(source, withDiagrams);
```

`mermaid` fences become inline SVG that follows the reader's color scheme
without JavaScript. Other fences reach the highlighter.

## Understand fallback behavior

Unsupported languages, failed diagrams, and engine exceptions keep escaped
`<pre><code>` output. `onHighlightError` and `onRenderError` observe them, with the
block's UTF-8 byte range; if an observer throws, the render call throws too.
Load the languages a document uses before rendering it; the
[highlighting and diagrams guide](/guide/code-rendering#load-languages-before-rendering)
shows how.

Hook output is inserted as trusted HTML. Use engines that escape the code they
receive. See [rendering and trust](/guide/rendering) for the shared boundary.

## Use the single-theme shortcut

`toHtmlWithHighlighter(source, highlighter, { theme })` and
`transformWithHighlighter()` pass each block to `codeToHtml()` and insert its
complete HTML. They are available since Ferromark 3 and suit one theme in HTML
output. Use the hooks above for JSX, theme pairs, or Ferromark's line
annotations.

Code hooks arrive with Ferromark 4.0. The
[highlighting and diagrams guide](/guide/code-rendering) compares them with
native plugin bundles.
