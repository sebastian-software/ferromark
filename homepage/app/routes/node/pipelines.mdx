# Build a Node.js Content Pipeline

import { RuntimeSwitch } from "../../components/runtime-switch";

<RuntimeSwitch topic="pipelines" />

Choose the result your application needs: an HTML string, UTF-8 bytes, or HTML
with document metadata. All operations are synchronous.

## Render a file from bytes

```js
import { toHtml } from "ferromark";
import { readFile } from "node:fs/promises";

const html = toHtml(await readFile("guide.md"));
console.log(html);
```

Every call that takes Markdown accepts `markdown: string | Uint8Array`, so the
`Buffer` that `readFile(path)` returns without an encoding goes in as it is.
Bytes render exactly like the string `buffer.toString("utf8")` returns, so a file
read as a `Buffer` produces the same HTML as the same file read with `"utf8"`.

## Get HTML, front matter, and headings

```js
import { transform } from "ferromark";

const source = "---\ntitle: Installation\n---\n# Installation\n\nRun `npm install ferromark`.";
const page = transform(source, { frontMatter: true });

console.log(page.frontMatter); // 'title: Installation\n'
console.log(page.headings[0]);
// { level: 1, id: 'installation', text: 'Installation' }
console.log(page.html);
```

Front-matter extraction is opt-in, including for `transform()`. The result is
raw text between `---` or `+++` delimiters; parse it with the YAML or TOML library
your application uses. Headings arrive in document order for application-owned
navigation or outline processing.
See the [shared pipeline concepts](/guide/pipelines) for output responsibilities.

## Reuse a renderer for a collection

```js
import { Renderer } from "ferromark";

const renderer = new Renderer({ headingIds: true, footnotes: true });
const pages = ["# First page", "# Next page"].map((source) => renderer.toHtml(source));
console.log(pages);
```

Options are fixed at construction. Keep one renderer per worker. It retains
parser scratch allocations while resetting headings, references, and footnotes
between documents. Each call returns its own HTML. `Renderer` provides
`toHtml()` and `toHtmlBuffer()`; use `transform()` when you need metadata.

## Send UTF-8 HTML directly

```js
import { toHtmlBuffer } from "ferromark";
import { createServer } from "node:http";

const server = createServer((_request, response) => {
  response.setHeader("content-type", "text/html; charset=utf-8");
  response.end(toHtmlBuffer("# Hello"));
});
server.listen(3000, "127.0.0.1");
```

`toHtmlBuffer()` returns a UTF-8 Node.js `Buffer` copied from the rendered
bytes. It avoids converting the HTML into a JavaScript string when the next
consumer wants bytes. Reusable renderers also expose `renderer.toHtmlBuffer()`.
With Markdown read as bytes, `toHtmlBuffer(await readFile(path))` takes bytes in
and returns bytes.

## Deploy under a subpath

```js
import { toHtml } from "ferromark";

const html = toHtml("[Guide](/guide)", { linkBasePath: "/docs" });
console.log(html);
```

This enables v2 site routing: internal absolute links, image sources, and
root-absolute raw HTML URLs use the base. Markdown links convert to index.html
routes. Check representative pages when migrating from v1.
