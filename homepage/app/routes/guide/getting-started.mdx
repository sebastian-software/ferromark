# Getting Started

Ferromark v2 lives in the Ferromark repository.
It combines an OX-Content-derived arena AST with Ferromark features and optimizations.
The first release candidate is `2.0.0-rc.1`. After publication, install it explicitly:

```sh
npm install ferromark@2.0.0-rc.1
cargo add ferromark@=2.0.0-rc.1
```

The npm `next` channel selects release candidates; `latest` stays on the stable
release. To build from source:

```sh
git clone https://github.com/sebastian-software/ferromark.git
cd ferromark
cargo test --workspace --all-features --locked
```

The repository toolchain selects the minimum Rust version from the workspace.
For Node development, use Node.js 22.13.0 or newer and the pinned pnpm version:

```sh
cd node
pnpm install --frozen-lockfile
pnpm build
pnpm test
```

The native package supports Node.js 22.12.0 and newer. CI builds native packages
for macOS, Windows, and glibc/musl Linux on x64 and arm64.
See [Quick Start](./quick-start) for local Rust and Node examples.
