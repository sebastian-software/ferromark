[v3-to-v4 migration guide](https://github.com/sebastian-software/ferromark/blob/main/docs/migration-v4.md)
for engine opt-ins and code-hook changes. For earlier versions, follow the
[v1-to-v2](https://github.com/sebastian-software/ferromark/blob/main/docs/migration-v2.md)
and [v2-to-v3](https://github.com/sebastian-software/ferromark/blob/main/docs/migration-v3.md)
guides first.

Ferromark turns Markdown into HTML for publishing tools, documentation sites,
and applications. Start with the Rust crate, or use the Node.js bindings from
JavaScript and TypeScript. The shared reference covers syntax and rendering behavior.
