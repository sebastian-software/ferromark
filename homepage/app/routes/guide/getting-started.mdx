# Documentation

The current release is v{version}. Ferromark v3 is a breaking upgrade from v2.
Read the [v2-to-v3 migration guide](https://github.com/sebastian-software/ferromark/blob/main/docs/migration-v3.md)
before upgrading. For a v1 upgrade, follow the [v1-to-v2 migration guide](https://github.com/sebastian-software/ferromark/blob/main/docs/migration-v2.md)
first, then the v2-to-v3 guide.

Ferromark turns Markdown into HTML for publishing tools, documentation sites,
and applications. Start with the Rust crate, or use the Node.js bindings from
JavaScript and TypeScript. The shared reference covers syntax and rendering behavior.
