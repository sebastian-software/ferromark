# Explore Performance Reports

Choose the evidence for your question:

| Question                                                   | Read                                                |
| ---------------------------------------------------------- | --------------------------------------------------- |
| How do native and Node.js APIs compare on the same inputs? | [Parser benchmarks](/guide/benchmarks)              |
| What do options and allocation reuse cost?                 | [Runtime profiles](/guide/workflow-benchmarks)      |
| Which syntax and rendering features exist?                 | [Feature comparison](/guide/feature-comparison)     |
| Which outputs have been checked?                           | [Correctness and compatibility](/guide/correctness) |

Each study retains the measured revision and its own baseline. Match input,
feature settings, output behavior, and lifecycle before comparing numbers.
