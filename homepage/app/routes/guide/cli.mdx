# Command Line

import { version } from "../../version";

Ferromark v{version} provides a Rust library and Node.js bindings. It does not ship the
v1 `ferromark` command; that command was removed in v2. Use an application
script or the retained stdin example.

## Render stdin from a repository checkout

```sh
printf 'Hello, **world**!\n' | cargo run --quiet --locked -p ferromark --example render_stdin
```

The example follows Rust rendering defaults, including raw HTML passthrough.
For untrusted input, build a small wrapper with `sanitize: true` using the
[Rust configuration guide](/rust/configuration).

For a JavaScript script, start with the [Node.js guide](/node/getting-started).
Node.js escapes raw HTML and filters unsafe URL schemes by default; see
[rendering and trust](/guide/rendering) for the available policies.

## Upgrade an existing application

When upgrading from v3, follow the [v3-to-v4 migration guide](https://github.com/sebastian-software/ferromark/blob/main/docs/migration-v4.md)
for code-engine opt-ins and code-hook changes. See also the current
[code rendering guide](/guide/code-rendering) for engine setup and hooks.
For earlier versions, follow the [v1-to-v2](https://github.com/sebastian-software/ferromark/blob/main/docs/migration-v2.md)
and [v2-to-v3](https://github.com/sebastian-software/ferromark/blob/main/docs/migration-v3.md)
guides first.
