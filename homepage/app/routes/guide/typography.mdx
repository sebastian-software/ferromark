# Optional typography

Ferromark preserves authored punctuation by default. An explicit typography
pass can convert prose punctuation after parsing. It does not run in the core
parser or renderer unless you opt in, and it never detects a document's
language.

## Node.js

Choose one supported language in the `typography` option:

```js
import { toHtml } from "ferromark";

const html = toHtml('"A *quoted* phrase"...', {
  typography: { language: "en" },
});
```

Supported language codes are `cs`, `da`, `de`, `en`, `es`, `fi`, `fr`, `it`,
`nb`, `nl`, `pl`, `pt`, `ru`, `sv`, and `uk`. Set `dashes: false` or
`ellipses: false` to disable either conversion independently.

## ASCII guillemet digraphs

If authors cannot easily type `«` and `»`, enable `guillemetDigraphs` while
parsing and choose a language for typography:

```js
const html = toHtml("Il a dit <<Bonjour>>.", {
  guillemetDigraphs: true,
  typography: { language: "fr" },
});
```

This renders `« Bonjour »`. Danish uses `»Bonjour«`; English uses `“Bonjour”`.
The parser option is off by default and only preserves doubled angle brackets
as text. Typography converts balanced pairs; unmatched markers and longer runs
stay literal. Code, math, and raw HTML stay protected. Standalone French
`<< Bonjour >>` absorbs its ASCII padding. A padded pair between word or number
operands, such as `a << b and c >> d`, stays literal because it is ambiguous
with a shift expression. In renderers that auto-link bare URLs, a URL
immediately next to guillemet markers keeps the ASCII markers so generated
quotes cannot become part of the link destination; the URL may still be linked.

For portable Markdown, prefer `"Bonjour"` with an explicit language such as
`typography: { language: "fr" }`. That does not require `guillemetDigraphs`.

In Rust, enable `ParserOptions::guillemet_digraphs` and also call
`TypographyOptions::with_guillemet_digraphs(true)` on the typography pass.

## Rust

The optional `ferromark-transforms` crate provides `TypographyPass` for the
native AST pipeline:

```rust
use ferromark_transforms::{
    TransformPipeline, TypographyLanguage, TypographyOptions, TypographyPass,
};

let mut pipeline = TransformPipeline::new();
pipeline.add(TypographyPass::new(TypographyOptions::new(
    TypographyLanguage::English,
)));
pipeline.run(&mut document, &context)?;
```

In both APIs, the pass pairs quotes across ordinary inline markup and protects
code, math, raw HTML, MDX expressions, image metadata, link destinations, and
detected autolinks. Paragraphs and other block containers have independent
quote context. Existing Unicode punctuation is preserved. The rules and
locale-specific conventions are described in the
[implementation guide](https://github.com/sebastian-software/ferromark/blob/main/docs/typography.md).
