# Markdown Syntax

Ferromark parses CommonMark and GFM. Choose the syntax your authors need in
[Rust](/rust/configuration) or [Node.js](/node/configuration), then choose an
independent [HTML trust policy](/guide/rendering).

## Everyday Markdown and GFM

CommonMark covers headings, paragraphs, lists, links, emphasis, images, and
code. GFM adds pipe tables, task lists, strikethrough, and autolinks. Ferromark
checks its output against the [CommonMark and GFM examples](/guide/correctness).

```text
# Release notes

- [x] Publish the docs
- [ ] Check the examples

Read the [guide](/guide/getting-started). ~~Outdated advice~~
```

## Publishing syntax

[Ferromark Flavored Markdown (FFM)](/guide/ffm) collects the opt-in syntax for
captions, attributed quotes, styled tables, inline spans, notes, and other
publishing needs. Its guide shows authored examples, the options that recognize
them, and links to the detailed rules. Enable only the extensions your content
uses; there is no single FFM switch.

The [feature comparison](/guide/feature-comparison) lists capabilities across
engines. [MDX boundaries](/guide/mdx) and [optional typography](/guide/typography)
have their own guides.
