# Customize Code Blocks in Rust

import { RuntimeSwitch } from "../../components/runtime-switch";

<RuntimeSwitch topic="highlighting" />

Use `HtmlRenderHooks` to replace output for selected AST nodes. The normal
`render()` path does not dispatch hooks; opt in with `render_with_hooks()`.

For syntax highlighting and Mermaid diagrams, use the optional `ferriki` and
`ferrigura` features described [below](#highlight-code-and-render-diagrams).
Ferromark keeps the code-block wrappers, line numbers, and annotations around
highlighted lines. The optional `ferriki-remote` feature enables release-pinned
CDN assets. See the
[native highlighting guide](https://github.com/sebastian-software/ferromark/blob/main/docs/native-code-highlighting.md)
for the adapter contract.

````rust
use ferromark::{
    Allocator, HtmlRenderContext, HtmlRenderControl, HtmlRenderHooks,
    HtmlRenderer, Parser,
};
use ferromark::ast::Node;

struct CodeRenderer;
impl HtmlRenderHooks for CodeRenderer {
    fn render_node(
        &mut self,
        node: &Node<'_>,
        cx: &mut HtmlRenderContext<'_>,
    ) -> HtmlRenderControl {
        if let Node::CodeBlock(block) = node {
            cx.write("<pre class=\"source\"><code>");
            cx.write_escaped(&block.value);
            cx.write("</code></pre>\n");
            HtmlRenderControl::Handled
        } else {
            HtmlRenderControl::Default
        }
    }
}
let source = "```rust\nfn main() {}\n```";
let allocator = Allocator::for_source_len(source.len());
let document = Parser::new(&allocator, source).parse().unwrap();
let html = HtmlRenderer::new()
    .render_with_hooks(&document, &mut CodeRenderer);
assert!(html.contains("class=\"source\""));
````

Return `Default` to use built-in output; return `Handled` after writing the entire
replacement. The hook sees fenced and indented code blocks. A highlighter adapter
can inspect the code, language, and metadata, then write its HTML here.

`cx.write()` inserts raw HTML, even when sanitization is enabled. Escape source
text with `write_escaped`, attributes with `write_attribute_escaped`, and URL
attributes with `write_url_escaped`. Validate URL schemes when supplying custom
URLs. Only insert highlighter output you trust. Theme colors from custom hooks
are escaped for HTML attributes, but their CSS values are not validated.

For code annotations, line numbers, and heading permalinks, inspect the existing
`HtmlRendererOptions` before writing a hook. [Rendering and trust](/guide/rendering)
explains the shared output boundary.

## Highlight code and render diagrams

Enable the optional features you need:

```sh
cargo add ferromark --features ferriki,ferrigura
```

`FerrikiHighlightHooks` implements the highlighting stage and
`FerriguraHooks` the whole-block stage. A tuple composes them; whole-block
replacements run before highlighting, and the first hook that returns a result
wins within each stage:

```rust
use ferromark::ferrigura::{Renderer, Value};
use ferromark::{
    Allocator, FerriguraHooks, FerrikiHighlightHooks, HtmlRenderer,
    Parser,
};

let source = std::fs::read_to_string("guide.md")?;
let allocator = Allocator::for_source_len(source.len());
let document = Parser::new(&allocator, &source).parse()?;

let renderer = Renderer::new(&Value::empty_object());
let diagrams = FerriguraHooks::new(renderer, "page")?;
let highlighting =
    FerrikiHighlightHooks::new(&mut highlighter, "github-dark");
let mut hooks = (diagrams, highlighting);
let html = HtmlRenderer::new()
    .render_with_code_hooks(&document, &mut hooks);
```

`highlighter` is a Ferriki highlighter with the theme and languages loaded.
`render_with_code_hooks` keeps normal inline rendering and dispatches only the
two code stages. For JSX, `FerrikiJsxHooks` and the same `FerriguraHooks`
implement `JsxRenderHooks`. To write your own engine adapter, implement
`render_code_block` for whole blocks or `highlight_code_block` for line
fragments; `ferromark::html_to_jsx` converts trusted HTML or SVG for JSX output.

The [highlighting and diagrams guide](/guide/code-rendering) compares the Rust,
Node.js, and native plugin integrations.
