# Ferromark

Ferromark parses authored Markdown and renders documents with optional code-block processing.

## Language

**Code-block plugin**:
An optional renderer extension that recognizes parsed code blocks and provides replacements or syntax highlighting.

**Whole-block replacement**:
Complete output supplied for a code block, including its surrounding markup. A handled replacement takes precedence over code highlighting.

**Code highlighting**:
Formatting of the displayed code while retaining the document renderer's wrappers, annotations, and metadata.
